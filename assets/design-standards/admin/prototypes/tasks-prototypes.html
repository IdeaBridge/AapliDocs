Assignment grid

Today's grid, tidied up.

What changes

  • "Split by" replaces the dropdown + Update + Remove buttons.
  • Task columns are grouped by Request / Response workflow, and each shows how many rows are assigned.
  • Assignees are chips: role, person or form field, each with its own icon and colour.
  • Empty cells say "Unassigned" in amber; "Only show gaps" filters to them.
  • Shift/Ctrl-click to multi-select replaces double-click, with a bar showing what's selected.
  • Template and Bulk add are buttons in the header.

Good for

  • Seeing everything at once.
  • Smallest change to build.

Watch out

  • Wide with many tasks.

Task list + panel

The same pattern as Features, Other settings and Users.

What changes

  • One row per task: who it's assigned to and how many regions or sites are covered.
  • The panel asks one question first: same people for everyone, or split by a field.
  • When split, each value gets its own picker, with "Fill empty" and "Copy first to all".
  • Splitting is chosen per task, so one task can be split while another isn't. That needs a backend change; today the split is shared by all tasks.

Good for

  • Clearest for new admins.
  • Scales to many tasks.

Watch out

  • Comparing tasks across one region means opening each task.

    Category first

    A master–detail layout: the categories on the left, the tasks for one on the right.

    What changes

    • The left list has search and a dot that turns amber where any task is unassigned.
    • The right side lists every task, grouped by workflow, each with a picker and a one-line description.
    • "Apply to all" on a task copies that assignment to every region and site.
    • Without a split, the left list disappears and only the task list shows.

    Good for

    • Many categories (dozens of sites).
    • Regional admins who think "who handles Leeds?".

    Watch out

    • No single view of one task across all regions.
    Suggestion: Option 1 to match roles and points; Option 3 if apps often have many categories.
