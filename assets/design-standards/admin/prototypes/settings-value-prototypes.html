Settings: see the values without opening a row

Organisation › Settings, three ways. Each shows the current value of every setting on the list, and selecting a row still opens its panel to change it. The data is made up.

A · Value column

The list stays as it is, with a third column for the current value and a short second line where it helps.

Good for

  • The smallest change from today
  • Scanning names and values side by side

Trade-offs

  • Three text columns get tight below about 900px; the description hides first
  • Long values (addresses) are cut to one line

B · Summary cards

One card per area with all its values, like the Account card in user details. Edit opens the same panel.

Good for

  • Seeing everything at once, including multi-part values (address, phone, email)
  • Matches the user details look

Trade-offs

  • Takes more space; less like the other lists (Features, Site design)
  • Descriptions move into the panel

Recommended: Settings is a handful of areas with several values each, so a dashboard of cards reads best.

C · Value under the name

Each row shows the name, then the value in larger text. The description moves to an info tooltip.

Good for

  • Phone-friendly: one column, no table
  • Values stand out more than in A

Trade-offs

  • Descriptions are hidden until hovered
  • Long values are cut to one line
